# Wireshark-Documentations
## Overview
This repository showcases my hands-on experience using Wireshark to inspect network traffic, interpret packet headers, and analyze communication across different network protocols.

Through my CSIA 210: Network Protocol Analysis coursework at Ivy Tech Community College, I developed practical skills in applying display filters, examining IPv4 and IPv6 traffic, identifying protocol messages, and interpreting network behavior through packet-level analysis.

The repository features my Midterm and Final capstone documentation as evidence of my ability to navigate Wireshark, investigate network communications, and explain technical findings.

## Technical Skills Demonstrated
### Packet Capture Analysis and Filtering
- Inspecting network traffic from packet capture files (.pcapng).
- Using Wireshark display filters to isolate specific protocols, IP addresses, and message types.
- Combining filter expressions with logical operators to narrow down relevant packets.
- Examining packet fields, source and destination addresses, and timestamps.
- Analyzing packet exchanges to understand communication between hosts and network devices.

### Network Protocol Analysis
| Protocol | Skills Demonstrated |
|----------|---------------------|
| IPv4 / IPv6 | Examining packet headers and addressing |
| TCP / UDP | Identifying transport protocols and ports |
| DHCP / DHCPv6 | Analyzing address configuration messages |
| OSPFv2 / OSPFv3 | Comparing routing protocol packets |
| ICMPv6 | Examining Neighbor Discovery messages |
| DNS | Filtering DNS queries and AAAA records |
| SSH | Examining encrypted network traffic |
| HTTPS / TLS | Analyzing encrypted web communications |

### IPv6 Network Configuration
- Examining Router Solicitation and Router Advertisement messages.
- Interpreting Neighbor Solicitation and Neighbor Advertisement exchanges.
- Identifying DHCPv6-assigned IPv6 addresses within captured traffic.
- Examining IPv6 configuration flags, including Managed (M), Other (O), On-link (L), and Autonomous (A).
- Investigating DHCPv6 server selection and relay-related information.
- Interpreting ICMPv6 Packet Too Big messages and Maximum Transmission Unit (MTU) values.

### Encrypted Traffic Analysis
- Identifying SSH and HTTPS traffic using Wireshark.
- Examining observable connection information while recognizing that application data is encrypted.
- Inspecting protocol information across the network and transport layers.
- Understanding how encryption limits visibility into application-layer content.

### Technical Documentation
- Documenting network protocol observations and findings.
- Supporting technical explanations with screenshots and packet-level evidence.
- Comparing protocol fields and behavior across different captured communications.
- Interpreting network traffic and explaining the significance of specific packet information.
